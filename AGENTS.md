# Workshop rules

Use short sentences and active voice. Preserve exact UI labels and commands.
Use ASD-STE100 as the writing target. Do not claim verified compliance without the applicable rules and dictionary.

Never change FORTIDEMO-2026-04. Its instructor key has admin permissions.
Use that environment only for read operations. Never distribute the instructor key.
Make workshop changes only in FORTINETAPACDEMO.
Use a unique participant suffix for every saved object.
Delete only objects created for the current workshop exercise.

Keep student pages focused on lab actions and concepts.
Put Concepts before Objectives in each lab. Explain the purpose before the actions.
Use titles and objectives that describe useful student outcomes.
Keep one main teaching point per lab in instructor-guide.md.
Make the concepts, tasks, and discussion reinforce that point. Do not repeat it as a new section in every lab.
Put delivery planning, credential administration, and build instructions in instructor-guide.md.
Remove explanations that repeat the interface or a previous instruction.

Write procedures against the live console. Record untested steps in internal/validation.md.
Keep original screenshots and tenant exports outside the tracked files.
Close unrelated notices before captures. Redact identifiers and credentials.
Use magenta callouts for controls. Keep evidence screenshots clear of callouts.
Add an observable checkpoint after each important step.
State what evidence students must find to check an answer.
Tie tasks and checkpoints to a useful decision or an observable result.
Do not ask students to copy counts or fill tables without a later use for that evidence.
Keep mechanical success checks for setup, saved configuration, and cleanup.
Use brief hints for practical help. Use What matters callouts for key lessons.
Teach command setup before the first command that needs it.
Introduce credentials, tools, participant IDs, and worksheets at their first use in a lab.
Keep setup checklists out of the workshop overview.
Rebuild the offline PDF after lab changes. Verify its rendered pages.
